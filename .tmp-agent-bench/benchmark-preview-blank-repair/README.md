# Preview Blank Repair

Started from the **Portfolio** Appora template.

## Template Intent

Creator/developer portfolio with hero, selected work, skills, process, contact CTA, and responsive project cards.

Best for: Personal brands, designers, developers, freelancers, student portfolios, and agency-style showcases.

## Development

```bash
npm install
npm run dev
npm run build
```

## Agent Notes

This project is intended to stay production-oriented: keep responsive layout, accessible labels, loading/empty/error states, and clean copy in place as the app evolves.
