# Nontechnical Landing

Started from the **Landing + Pricing** Appora template.

## Template Intent

Conversion-focused landing site with product story, feature grid, pricing, FAQ, and contact CTA.

Best for: Product launches, agency offers, waitlists, SaaS landing pages, and portfolio offers.

## Development

```bash
npm install
npm run dev
npm run build
```

## Agent Notes

This project is intended to stay production-oriented: keep responsive layout, accessible labels, loading/empty/error states, and clean copy in place as the app evolves.
